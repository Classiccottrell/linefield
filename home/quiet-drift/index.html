How it lands in your project.

No package to install. Everything below happens in a browser tab.

  1. 1

    Open a piece, tune it

    Every piece ships the same fourteen shared controls (speed, density, palette, and so on) plus a few of its own. Drag until it looks right for your site.

  2. 2

    Export baked, or export source

    Baked HTML hardcodes your settings, strips the panel, and inlines every shared module into one file, ready to paste anywhere. Source gives you the same piece unbaked, if you'd rather keep the controls and edit the logic yourself.

  3. 3

    Paste it in

    One <script type="module"> tag, one canvas. No bundler, no npm install, no framework requirement: it's plain ES modules the browser runs directly. Full contract in the docs and Contributing guide.

MIT licensed. Use it in commercial work, fork it, strip it for parts; no attribution required, though it's appreciated. The controls on this page talk to the live piece the same way the exported control panel does: one shared write path, setValue(), no separate demo-only code.
